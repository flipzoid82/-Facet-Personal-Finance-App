## In-scope outcome and proof vocabulary

A user can **actually run** a local browser application using deterministic, unmistakably fictitious accounts/transactions; navigate Overview → Accounts → account detail → Transactions; inspect source data including pending/uncategorized/unidentified records; edit category, label, or notes without modifying source facts; close and restart the process and retain the edits. The app has truthful synthetic freshness/coverage, usable empty/loading/failure states, responsive desktop/mobile viewport, keyboard-accessible controls and automated evidence. Source, tests, build/run/stop and observed run results are necessary; static screenshots, API-only simulations and a document-only delivery are insufficient. A localhost development UI is **not** a secure real-finance or real-phone/LAN release.
