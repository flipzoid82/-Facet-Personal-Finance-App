## 5. Consent, data minimization, handling and deletion

No workflow participant receives bank credentials, access tokens, OAuth codes, full API responses, account names/masks, personal transactions, balances, bank screen recordings or identifiable account-type inventory. Owner alone signs in directly to genuine bank/Plaid pages; require manual verification of URL and scope, not automation or delegated login. Store long-lived access tokens server-side using independently protected encryption keys (never browser local storage, logs or Git); restrict and audit endpoints, keep only consented and necessary data, prefer ephemeral field-presence flags and local-only sanitized data comparisons. Do **not** move real test data into the legacy PersonalFinanceApp, public PR, Issues, ChatGPT, CI artifacts, or T7 existing folders.

A future informed-consent brief must separately disclose: (1) specific institution and environment, (2) per-product access scope and selected accounts, (3) one non-replenishing Trial slot and any potential costs; (4) access location, host/phone/admin/network changes and reversals; (5) exact data fields, encryption, custody, local retention cap, deletion and provider revoke path; (6) cancellation/partial failures and six-hour session limit; (7) default revoke/delete after test vs *new* explicit keep choice. Consent is revocable; revoked provider data cannot be retained contrary to provider terms/required law. No user choice about retained historical financial data supersedes retention obligations. Any error disclosure is redacted and private.

**Retention design:** raw results never enter shared logs; temporary necessary raw source data only in already-proven encrypted, least-privilege local storage while actively testing, and deletion/revocation documented promptly at the end. Any backup containing test data must be cryptographically and physically purgeable consistent with verified retention policy, or real test is blocked. Redacted public evidence may retain only source reference, tested mode, result category, field presence/absence and independent verification, not personal financial relationship details or secrets. Evidence of item removal does NOT restore a Trial allowance.
