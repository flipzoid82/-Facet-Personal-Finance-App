## P01/P02 — browser and Hosted Link contract matrix (I003-C01, C05)

The proposed environment is one user's on-demand local application, ordinary Windows desktop and Android Chrome browsers, `hosted_link.is_mobile_app=false`, no owned domain, registered HTTPS redirect, public receiver or persistent online host. **General documentation support is separate from institution-specific verification.** Each cell below addresses the exact proposed design, not whether some different Plaid design exists.

| Case | Public contract and negative oracle | Exact design classification |
| --- | --- | --- |

Popup blocking, bank-specific OAuth requirements, token entitlement and completion are unobserved. | **NOT CONFIRMED** for Navy Federal; general initial path is **SUPPORTED WITH CONDITIONS**. A desktop success would not prove mobile. |
| Android **ordinary Chrome initial** OAuth | S01 says mobile web generally uses a new tab without a redirect, while embedded webviews require redirect/reinitialization. Ordinary Chrome must not be conflated with a native SDK, Custom Tab inside an app, or an embedded browser. | **NOT CONFIRMED** for Navy Federal and the owner's device; general browser path is **SUPPORTED WITH CONDITIONS**. |
| Desktop ordinary-browser **same-Item update/consent repair** without redirect | S01 and S02 instruct OAuth update mode to specify a redirect URI. A different Hosted route remains a separate question. |
| Android ordinary-browser **same-Item update/consent repair** without redirect | The same S01/S02 update requirement applies; native Android SDK package registration is a distinct integration and cannot be imported into an ordinary browser claim. | **REFUTED** as a documented *standard no-redirect update configuration*. Actual Navy Federal repair remains **NOT TESTED**. |
| Browser Hosted Link **same-Item update** with `is_mobile_app=false` and no owned domain/redirect | S03 says Hosted Link supports update mode and may use `/link/token/get`; its native-app instructions explicitly require a redirect when `is_mobile_app=true`.
